# qinit-client-c

The C interface of the qinit client library: `libqinit_client_c` (static archive and shared
object) with the header `include/qinit_client.h`. The header is generated by cbindgen from this
crate and checked in; the `header_is_current` test fails when it is stale. The enum words in it
(`QINIT_STATE_*`, `QINIT_ACTION_*`, `QINIT_REPORT_*`, …) are the numbers of
`docs/control-protocol.md`.

## Linking

```sh
cargo build --release -p qinit-client-c
cc -std=c11 -I crates/qinit-client-c/include prog.c \
   target/release/libqinit_client_c.a -lpthread -ldl -lm
# or against the shared object: -L target/release -lqinit_client_c
```

The static archive carries the Rust standard library, which needs `-lpthread -ldl -lm`.

## Error model

A function that can fail returns `int`: 0 on success, otherwise the kind of the failure:

| Kind | Meaning | `qinit_last_error` gives |
| --- | --- | --- |
| `QINIT_E_ERRNO` (1) | a system call failed | `code`: the errno |
| `QINIT_E_PROTOCOL` (2) | the server's message does not decode | `code`: the decode error number |
| `QINIT_E_SERVER` (3) | the server refused the request | `code`: `QINIT_CODE_*`, `detail` |
| `QINIT_E_UNEXPECTED` (4) | the connection closed, or the reply does not answer | |
| `QINIT_E_ARGUMENT` (5) | a NULL pointer, a string too long or not UTF-8, a word out of range, or a call the client cannot make now; nothing was sent | |

`qinit_last_error(c, &e)` fills `e` for the last call on `c`; with a NULL `c` it gives the failure
of this thread's last `qinit_connect`, which has no client to keep it. A call with a NULL client
is `QINIT_E_ARGUMENT` and records nothing. `qinit_watch_next` and
`qinit_pidfd_exit` succeed with 0, 1 or 2 and fail with the negated kind (`-QINIT_E_*`).

Strings in are NUL-terminated UTF-8; names out are copied into `QINIT_NAME_MAX + 1` (97) bytes,
NUL-terminated. Every out-structure is the caller's; the library allocates only the client. A
client is used from one thread at a time. Descriptors passed in are borrowed for the call; a pidfd
returned is the caller's to close. After `qinit_watch` the client accepts only
`qinit_watch_next`, `qinit_fd`, `qinit_last_error` and `qinit_close`; after a refused one, only the
last three (every other call is `QINIT_E_ARGUMENT`).

`qinit_status` is both a function and a structure: write `struct qinit_status` for the
structure. Every other structure also has a typedef of its own name.

## Example

```c
#include <stdio.h>
#include "qinit_client.h"

int main(void) {
    qinit_client *c;
    qinit_error e;
    if (qinit_connect(NULL, &c) != 0) {
        qinit_last_error(NULL, &e);
        fprintf(stderr, "connect: kind %d code %d\n", e.kind, e.code);
        return 1;
    }
    struct qinit_status s;
    int rc = qinit_status(c, "db", &s);
    if (rc != 0) {
        qinit_last_error(c, &e);
        fprintf(stderr, "status: kind %d code %d detail %u\n", e.kind, e.code, e.detail);
    } else if (!s.is_instance) {
        printf("%s: state %u detail %u\n", s.node.name, s.node.state, s.node.detail);
    }
    qinit_close(c);
    return rc != 0;
}
```
